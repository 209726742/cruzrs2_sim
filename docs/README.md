## 整理规则

1. 新的项目进度或操作说明放入 `docs/current/`，使用 `<用途>_MMDD.md` 命名，例如 `Sorting_Roll场景进度_0820.md`。
2. 对工作文档做任何内容更新时（包括链接或排版），都要将文件名末尾的 `MMDD` 同步改为更新当天日期，并更新本索引及代码中的全部引用。
3. 文档被新版本取代后移入 `docs/archive/`，保留最后更新日期，并在开头注明归档状态。
4. `docs/README.md` 是固定入口，不增加日期后缀，只更新文件开头的“更新时间”。
5. 一次性监控 PID、已完成任务清单和原始问题便签不长期保留。
