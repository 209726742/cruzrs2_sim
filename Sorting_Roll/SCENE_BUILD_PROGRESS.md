# Sorting Roll 场景实施记录

## 目标

为 CRUZR S2 搭建“从机器人右侧桌面拿取橡胶棒，并放入机器人前方架子顶层槽位”的仿真场景。实现将参考 `Scene_Pic` 中的布局，并复用仓库内既有搬运橡胶条任务的可靠做法。

## 已知实物尺寸

- 架子：正面长 0.63 m、侧面宽 0.40 m、高 1.40 m。
- 架子目标层：底面离地 1.00 m、顶部离地 1.20 m。
- 目标槽：底部挡板高 0.05 m、槽宽 0.025 m；中间横杆距目标层底部 0.13 m。
- 桌子：长 0.60 m、宽 0.52 m、高 1.00 m。
- 橡胶棒：长 0.50 m、直径 0.025 m；材质偏硬，初始状态保持横直。
- 场景间距：桌子左侧边缘到架子为 1.00 m。

## 初始约定（待资产与旧场景检查后确认）

- 仿真单位统一为米。
- 架子位于机器人正前方，桌子位于机器人右侧。
- “距离架子 1.00 m”暂按桌子左侧边缘到架子最近边缘的水平净距理解。
- 资产模型只做与实物尺寸一致的均匀或分轴缩放；碰撞体、质量和抓取参数将在确认模型拓扑后设置。
- 最终坐标和朝向以参考图、机器人关节可达性及无碰撞要求共同确定。

## 验收标准

1. 场景可由项目规定的启动方式成功加载，无缺失资产或路径错误。
2. 架子、桌子和橡胶棒的仿真尺寸与上述实物尺寸一致。
3. 架子在机器人前方，桌子在机器人右侧，二者满足 1.00 m 的边缘距离约束。
4. 橡胶棒稳定放置在桌面上，目标位姿位于架子顶层槽内。
5. 场景提供明确的抓取初始位姿、放置目标位姿及任务成功判定。
6. 至少通过静态检查和可执行的场景加载/烟雾测试；若当前机器缺少仿真运行环境，需记录可复现的阻塞原因与运行命令。

## 最终使用说明

从仓库根目录执行：

```bash
# 生成并完整检查布局、桌面初始状态和目标槽正例
Sorting_Roll/run_scene.sh check

# 生成初始布局和目标槽近景预览
Sorting_Roll/run_scene.sh preview

# 打开 CRUZR 双臂/底盘遥操作查看器（默认 RTX 4090 EGL GPU）
Sorting_Roll/run_scene.sh view

# 必要时手动回退到 CPU passive 查看器
TELEOP_VIEWER=passive Sorting_Roll/run_scene.sh view
```

若换机器，使用 `RL_MJX_PY=/path/to/mujoco/python` 指定带 MuJoCo 3.9 和上述 OpenCV 依赖的解释器。`view` 模式默认使用 EGL GPU；无显示环境下使用 `check` 或 `preview`。
