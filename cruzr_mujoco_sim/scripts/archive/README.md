# 脚本归档

这里保存 33 个不属于当前 CRUZR S2 双物料正式链的源码文件：

- `ecu/`：18 个旧 ECU/纸箱流水线文件；
- `rl/`：11 个旧单立柱 RL/DAgger 文件及 2 个专属测试；
- `history/`：旧单物料专家和双物料 `.orig.py` 备份。

本次整理没有永久删除这些源码。归档的含义是“保留用于查阅或历史复现”，不是“当前可直接运行”：

- 它们没有纳入当前 `scripts/tests/` 的 65 项回归；
- 部分文件仍保留移动前的相对路径、旧相机、旧 state/action 或旧输出目录假设；
- 不得把归档 episode 与当前双物料训练源混用。

如果以后确实需要恢复某条历史线，先在独立分支或工作副本中：

1. 明确要恢复的是 ECU、单立柱 RL 还是历史专家；
2. 修复该子目录内的导入、shell 和资源路径；
3. 恢复它自己的测试和 smoke；
4. 通过验证后再建立新的正式入口。

不要为了运行归档脚本而把文件直接散回 `scripts/` 顶层。
